Complete3D — Navigation on the raw ScanNet++ scan vs a GenRecon reconstruction

Simulation readiness: PointNav in Habitat on two worlds per scene — S = the raw ScanNet++ laser scan, R = the GenRecon reconstruction of the same scene from 32 DSLR frames (image-only baseline) · 124 ScanNet++ test scenes × 50 point-goal episodes sampled on S and carried to R (start / goal snapped within 0.25 m; an episode that cannot be placed or connected on R counts as a failure) · the same frozen agents on both arms (DD-PPO depth = headline, DD-PPO RGB, navmesh oracle), greedy actions, Gibson PointNav settings (0.25 m / 10°, success within 0.2 m, 500 steps) · SPL is scored against the scan's own shortest path on both arms · image-only benchmark · scan-conditioned · VGGT-evidence ·

Agents on identical episodes (120 scenes, 6,000 episodes)

Δ = R − S with a 95 % paired bootstrap CI over scenes. Unplaceable = episodes whose start or goal is more than 0.25 m from R's navmesh or disconnected on R (counted as failures in SR/SPL). Runnable-only = SR / SPL on R over the placeable episodes alone. The RGB agent sees flat-shaded vertex colours on both arms (no textures), so its S row is a rendering-domain control, not a ceiling; the depth agent is the geometry claim.

Map level (medians over scenes)

    Computed on the navmeshes the agents walked, on one shared 5 cm raster per scene. Phantom free space = navigable on R only; hole-filled = the scan has no floor there (a scan hole, closed morphologically), hallucinated = the scan has floor but no free space; lost = navigable on S only. Path ratio = R's shortest path / S's shortest path per episode (< 1: the scan's holes were filled; > 1: detours).
