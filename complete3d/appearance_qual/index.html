Complete3D — stage-3 appearance on ScanNet++ val (8 input views): qualitative results

All 50 scenes of the official ScanNet++ validation split, 8 input DSLR views (the Table 2 setting). Geometry is identical in recipe for every row: Complete3D-PreserveLoss stage 1 (D41 B, 20k) with VGGT points from the 8 views (estimated depth), stock stage 2. What changes is stage 3, the texture model: Stock = GenRecon's released texture model (images only); Arm A = the colour-evidence stream (the 8 photos projected onto the stage-2 mesh → 128³ colour grid → zero-initialised into the stage-3 conditioning), trained on SAGE only; Arm B = the same stream plus a decoded base-colour loss against real ScanNet++ colour targets at observed voxels (20k). Each is shown raw, + paste (photo colour copied onto the observed surface) and + paste + palette transfer (generated regions recalibrated per scene to the pasted observed colour). Arm B (outlined in blue) is the first stage 3 that keeps the observed colour on its own.

Section 1 shows each variant's full textured output from one shared camera per scene (40° elevation, azimuth 210°, whole scene in frame, ceiling cut at the median input-camera height), with the laser mesh's own vertex colour from the same camera as reference. Stock rows reuse the Table 2 meshes; arms A and B regenerated stages 1–2 at the same seed (arm A on L40S, arm B on RTX6000B), so the geometry differs slightly between the three blocks. Section 2 shows 4 of each scene's official held-out DSLR frames: the photo, the pixel-class mask used by the metrics (observed = seen by an input view, generated = never seen, seam = 8 px band between them), and all nine variants rendered with the metric's own render function at half resolution, unlit vertex colour, pixels not covered by the mesh left white. Tiles show exactly what the table scores (raw colour, no per-frame calibration).

Numbers behind the page (official val, 8 views, paired n = 50; results/d45_armB20k_val.md): observed-pixel PSNR is the headline, "cal" = after the per-frame affine colour calibration, "gen" = generated pixels only, FID over generated regions.
