Complete3D — ScanNet++ val, reconstruction from 32 views: geometry

All 48 scenes of Table 1 (official ScanNet++ validation split, 32 input DSLR views). Geometry only: every reconstruction and the GT laser mesh are drawn in uniform grey with headlight shading; only the input views and the estimated points carry colour. Complete3D-TS (blue frames) = our full model; estimated depth = VGGT-Ω points as the depth input, sensor depth = depth from the scan at the input views.

Columns: 4 of the 32 input views (drawn once per scene with a fixed seed) · the estimated points (the VGGT-Ω 32-view point cloud that the estimated-depth line takes as input, subsampled to 8,000 points, coloured from the input photos) · each method's output mesh · the GT. Every 3D tile of a row uses the same camera (40° elevation, whole scene in frame) and the same cut: ceiling and upper walls above 0.6 m over the median input-camera height are removed from every mesh, the points and the GT, so the room interior is visible. The camera and cut for a scene are the same on the 32-view and 8-view pages. CD under each tile = that scene's Chamfer distance (m) in Table 1.
